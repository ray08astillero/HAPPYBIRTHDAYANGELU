# Birthday Surprise — Angelu 🎂

## Files
- `index.html` — main birthday surprise
- `album.html` — 10-photo timeline opened in a new tab
- `style.css` / `album.css` — design
- `script.js` — confetti, music, modals, cake candles
- `assets/` — put your photos, video, and music here

## Add your own files

Put these files in exactly these locations:

1. `assets/celebrant.jpg` — big photo of Angelu
2. `assets/birthday-video.mp4` — video message
3. `assets/message.jpg` — message image
4. `assets/happy-birthday.mp3` — birthday song
5. `assets/photos/photo1.jpg` through `photo10.jpg` — album photos

The website is already coded to show placeholders if the photos are missing.

## Important
Browsers normally block websites from automatically playing audio before the user interacts with the page. This design starts the birthday song immediately after the user taps **"Tap to see"**, which is the reliable way to satisfy autoplay restrictions.

## Run it
You can simply open `index.html` in a browser. For best results, upload the entire folder to GitHub Pages or another static host.
